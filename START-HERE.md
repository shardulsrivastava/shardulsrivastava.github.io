## 🎨 Customization Examples

### Change Colors
Edit `tailwind.config.ts`:
```typescript
colors: {
  primary: '#YOUR_COLOR_HERE',
  secondary: '#YOUR_COLOR_HERE',
}
```

### Add Blog Post
Edit `src/data/posts.ts`:
```typescript
{
  id: 'my-post',
  title: 'My Post Title',
  excerpt: 'Short description...',
  date: '2024-09-24',
  category: 'Tech',
  tags: ['tag1', 'tag2'],
  featured: false,
}
```

### Update Your Info
Edit `src/components/Footer.tsx` and add your social links.
